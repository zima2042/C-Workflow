这周主要是把数组、函数和结构体结合到一起练了练。之前写指针就一直报错，现在算是理解得更深一点了。



一 这周学了些啥



数组传参：以前一直以为数组传进去，在函数里用 sizeof 算就行。结果一跑发现算出来的全是指针的大小。后来才知道数组一当参数传递，就会退化成指针，所以必须老老实实把数组长度 n 作为参数也传进去。



结构体和联合体：结构体里的成员各占各的内存，互不干扰；联合体（union）是所有成员挤在同一块内存里，同一时间只能有一个成员有效，大小由最长的那个成员决定（前提是不考虑对齐）。在没看过这段之前，我以为union也能同时存数据，差点写错。



动态分配内存：因为题目要求字符串“不定长”，我试过直接 char str\[10000]，但这样既不安全又浪费。后来改用 malloc 和 realloc，空间不够就翻倍扩容，最后记得用 free 释放掉，防止内存泄漏。



宏定义和位运算：用 8421 码算了下十六进制的题。搞清楚了 #define 只是纯粹的文本替换，没有类型检查，而 const 是有着类型检查的常量。



二 踩过的坑和解决过程



坑1：输入换行符的问题：用 fgets 读入字符串时，回车会被当作字符读进去。我一开始直接把它算进 Others 里，导致数字总是多1。后来手动把 \\n 替换成了 \\0 才解决。



坑2：结构体指针解引用：写改错题时，我对一个结构体局部变量用了 s->id，编译怎么都不通过。后来才发现，只有指针才能用 ->，普通变量得用 .，。



坑3：数组越界和VS警告：为了图省事写 for (int i = 1; i <= 5; i++)，直接越界。另外 VS 对 scanf 有安全警告，我加了 #define \_CRT\_SECURE\_NO\_WARNINGS 1 之后，警告全消失了，看着终于舒服了。



三 其他学习内容

学习了一些与AI相关的知识

交叉熵损失：本质是衡量预测概率分布与真实标签分布的差距。它是连续可导的凸函数，能让梯度下降平稳滑到底。如果不用 Softmax 归一化，输出会过热，梯度直接消失；也不能用绝对阈值硬截断，否则梯度清零，模型直接停机。



KNN vs 自注意力机制：KNN 是非参数化的“硬选择”，计算全局距离，挑出最近的一个邻居直接作为结果；自注意力是参数化的“软聚合”，通过缩放点积计算权重，对全部 Value 向量进行加权混合。一个是找人抄，一个是开会综合意见。

大模型数学推理：不是死记硬背的过拟合，而是把推理步骤拆成可组合的小逻辑块，靠多层注意力组合泛化。思维链相当于给模型一张草稿纸，再用形式化验证器兜底校验一遍。

多层网络架构：层数是超参数，在设计时确定（或通过 NAS 搜索），训练过程只更新权重，不会自动改变层数。

学习了一些YOLO相关的知识

YOLO 直接回归目标框 + 类别概率，速度快，适合实时画面（直播转播、视频跟踪）；不是图像分割，只预测矩形框。

Anchor 机制：物体的中心点落在哪个网格，就由这个网格负责预测它，而不是物体占了几个网格就有几个网格负责。

现代 YOLO 采用多层独立网格，每一层的每个网格都可以输出多个预测框（不是只能输出 1 个），每层互相独立预测。

anchor-Based 与 Anchor-Free。

根本局限：多层卷积下小目标特征图退化成1-2个像素点，直接糊掉，调参无法解决。

结合自身优势：YOLO最终要落地在嵌入式端。相对于在云端堆算力，用 C/C++ 接推理引擎（NCNN/TensorRT），在有限内存下进行内存对齐与量化，才是嵌入式开发者的不可替代性。
